- # EPIC 5 — Tasks
    - ## Epic Scope
    - Task lifecycle and assignment within projects.
    - 
    - ## Feature 5.1 — Task Creation
    - ### User Story
    - As a member, I want to create tasks so that work can be tracked.
    - ### Services / Actions Used
        - **Action:** `CreateTask`
        - **Service:** `TaskService`
        - **Service:** `AuthorizationService`
    - ### Domain Rules
        - Task belongs to project.
        - Project must belong to same workspace.
        - Default status must be defined (e.g., Backlog).
    - ### Tasks
        - **DB**
            - `tasks`:
                - id
                - workspace_id
                - project_id
                - title
                - description
                - status
                - assigned_to_user_id (nullable)
                - due_date (nullable)
                - priority
                - timestamps
                - soft deletes
        - **API**
            - POST /tasks
        - **Tests**
            - project cross-workspace blocked
            - default status set
    - 
    - ## Feature 5.2 — Assignment
    - ### User Story
    - As a member, I want to assign tasks so that responsibility is clear.
    - ### Services / Actions Used
        - **Action:** `AssignTask`
        - **Service:** `AssignmentService`
        - **Service:** `AuthorizationService`
        - **Service:** `NotificationService`
    - ### Domain Rules
        - Assignee must be workspace member.
        - Assignment change must be recorded.
        - Assignment may trigger notification.
    - ### Tasks
        - PATCH /tasks/{id}/assign
        - Validate membership
        - Trigger notification
        - Add history record
